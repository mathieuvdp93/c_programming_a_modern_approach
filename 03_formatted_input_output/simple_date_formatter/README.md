## 💡 What I Learned

- you can use characters in scanf function call, so scanf("%d/%d") with the input 4/3 will match 4 with the first variable, then will look at the next char which is / if it matches the char in scanf it will discard it and continue with the next conversion which will be 3 in the second variable.
